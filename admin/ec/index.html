hubEC一元管理

8ECを商品・在庫のマスターにして、楽天・Amazon・Yahoo!への出品をまとめて扱います。在庫は1か所だけで持ち、どのモールで売れても同じ数字が減ります。
ここで扱うのは新品SKUです。オークション仕入れの中古（1台ずつの現物管理）は、これまでどおりEC在庫管理で扱ってください。

ログイン

事務の共有アカウント（ID: zimu）でログインしてください。

warning_amber先にセットアップSQLの実行が必要です

この画面が使う表がまだ作られていません。Supabase の SQL Editor に admin/ec-master-setup.sql の中身をすべて貼り付けて実行してください。何度実行しても安全です。

在庫はSKUごとに1つだけ持ちます。ここで増やす・減らすとすべてのモールの在庫数が同時に変わり、理由と日時が履歴に残ります。数字を直接書き換えず、「＋」「−」か「調整」を使ってください。
マスターの販売価格と、モールごとの価格をまとめて見ます。最低販売価格を下回る値は赤で警告します（保存自体は止めません）。変更したところは青くなり、下のバーからまとめて保存します。
